# 📱 PhonePick - AI Phone Recommendation System

PhonePick is an AI-powered smartphone recommendation application that helps users find suitable phones based on their **budget** and **usage requirements**.

The application uses a Node.js and Express.js backend integrated with the **Anthropic Claude API** to process natural-language requirements and generate personalized smartphone recommendations.

---

## 🚀 Features

- 🤖 AI-powered smartphone recommendations
- 💰 Budget-based phone suggestions
- 🎯 Usage-based recommendations
- 🧠 Natural-language processing using Anthropic Claude API
- 📱 Smartphone dataset containing phone specifications and pricing information
- 🔌 REST API for generating recommendations
- 🌐 CORS-enabled backend for frontend integration
- 🔐 API key managed through environment variables
